# Fraud Risk Strategy & Financial Loss Optimization

## Business Problem
Financial institutions must detect fraudulent transactions while minimizing fraud-related losses and unnecessary disruption to legitimate customers.

## Project Objective
Analyze transaction-level fraud patterns, develop a fraud probability model, and evaluate decision thresholds to minimize expected financial losses.

## Dataset
IEEE-CIS Fraud Detection (Kaggle)

## Tools
- SQL
- Python (pandas, scikit-learn, statsmodels)
- Logistic Regression
- Data Visualization

## Key Business Questions
1. Where is fraud risk concentrated?
2. What factors are associated with fraudulent transactions?
3. How accurately can fraudulent transactions be identified?
4. Which risk thresholds should trigger approval, review, or decline?
5. Which decision strategy minimizes expected financial losses?
